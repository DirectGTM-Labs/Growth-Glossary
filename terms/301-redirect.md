# 301 Redirect

## Definition

An HTTP permanent redirect indicating that a resource has moved to a different URL.

## 中文定义

301 永久重定向通过 HTTP 状态告诉客户端和搜索系统，资源已经永久移动到新的 URL。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit 301 Redirect during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
