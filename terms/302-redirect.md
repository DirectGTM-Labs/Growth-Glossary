# 302 Redirect

## Definition

An HTTP temporary redirect indicating that a resource is temporarily available at another URL.

## 中文定义

302 临时重定向表示资源暂时通过另一个 URL 提供，原地址的永久性关系与 301 不同。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit 302 Redirect during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
