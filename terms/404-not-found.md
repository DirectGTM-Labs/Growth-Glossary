# 404 Not Found

## Definition

An HTTP client-error response indicating that the server cannot find the requested resource.

## 中文定义

404 Not Found 表示服务器无法找到请求资源的 HTTP 客户端错误状态。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit 404 Not Found during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
