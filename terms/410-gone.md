# 410 Gone

## Definition

An HTTP client-error response indicating that the requested resource is intentionally no longer available.

## 中文定义

410 Gone 表示服务器明确声明请求资源已经被有意永久移除的 HTTP 客户端错误状态。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit 410 Gone during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
