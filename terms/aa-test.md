# A/A Test

## Definition

An A/A test randomly assigns users to two groups that receive the same experience. It is used to validate randomization, instrumentation, metric computation, and the experiment platform rather than to test a product difference.

## 中文定义

A/A 测试将用户随机分配到两个获得完全相同体验的组，用于验证随机分流、埋点、指标计算和实验平台，而不是验证产品差异。

## Why It Matters

A/A tests can expose assignment or measurement problems before a consequential A/B test is launched.

## Example

A platform runs identical experiences in both groups and checks allocation ratios and metric distributions for unexpected anomalies.
