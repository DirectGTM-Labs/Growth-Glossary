# Alias

## Definition

An alias is an explicit identity-linking operation that tells an analytics or data system that two identifiers should be treated as belonging to the same entity.

## 中文定义

在代码层面告诉数据平台“这个匿名设备 ID 其实就是刚刚注册的 UID 9527”，从而避免历史归因断裂。

## Why It Matters

Understanding Alias helps a growth practitioner make clearer decisions, define measurement correctly, and avoid confusing a useful tactic or implementation detail with a universal growth law.
