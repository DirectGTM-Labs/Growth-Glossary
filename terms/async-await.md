# Async/Await

## Definition

Async/await is JavaScript syntax for writing asynchronous control flow in a style that resembles synchronous code while operating on promises.

## 中文定义

JS 中的优雅魔法，挂起后台线程耐心等待数据库查询结果返回，且绝不卡死当前用户操作界面。
