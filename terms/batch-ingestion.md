# Batch Ingestion

## Definition

Batch ingestion collects data over a defined interval and loads it downstream as discrete batches rather than processing each event immediately.

## 中文定义

批处理摄取是按预定时间间隔收集数据，再以离散批次向下游加载，而不是逐条实时处理。

## Why It Matters

Batch ingestion is often simpler and more cost-efficient when low latency is not required.

## Example

An advertising platform exports daily campaign data, which is loaded into a warehouse every morning.
