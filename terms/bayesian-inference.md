# Bayesian Inference

## Definition

Bayesian inference represents uncertain quantities with probability distributions and updates those distributions using observed data and a specified likelihood model, producing a posterior distribution.

## 中文定义

贝叶斯推断使用概率分布表示不确定参数，并根据观测数据和指定的似然模型更新这些分布，得到后验分布。

## Why It Matters

Bayesian methods can express uncertainty directly through posterior distributions and can be useful for sequential decision-making when the model and prior are appropriate.

## Example

An experiment updates the posterior distribution of the conversion-rate difference as new observations arrive and estimates the probability that one variant exceeds another.
