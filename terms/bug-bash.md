# Bug Bash

## Definition

A bug bash is a focused, collaborative testing session in which multiple participants systematically exercise a product or release to identify defects, usability problems, and other issues before or after launch.

## 中文定义

Bug Bash 是一种集中式协作测试活动，由多名参与者系统性地操作产品或版本，以发现缺陷、可用性问题及其他风险。

## Why It Matters

Collaborative exploratory testing can expose edge cases that automated tests or individual review may miss.

## Example

Before an experiment launch, product, engineering, and analytics participants exercise each variant and verify both UI behavior and event payloads.
