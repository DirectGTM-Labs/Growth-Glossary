# Caching

## Definition

Caching stores reusable data or computation results closer to where they are needed so repeated requests can be served faster or more cheaply.

## 中文定义

把刚刚花大力气算出来的数据放在门口（如 Redis 或 CDN），下一个用户来直接拿走，极度省钱。
