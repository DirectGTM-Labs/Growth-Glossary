# Canonical URL

## Definition

A canonical URL is the preferred representative URL for a set of duplicate or near-duplicate pages, communicated to search engines through canonical signals.

## 中文定义

告诉搜索引擎，虽然我有好几个页面长得差不多，但请把流量和权重全部算在这个最核心的页面头上。
