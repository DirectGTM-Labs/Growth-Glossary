# Composable CDP

## Definition

An architecture that uses an existing cloud data warehouse as the primary customer-data foundation while separate tools provide identity, audience, and activation capabilities.

## 中文定义

可组合 CDP 是以现有云数据仓库作为核心客户数据底座，再通过独立组件完成身份、受众和激活能力的架构方式。

## Why It Matters

It helps teams coordinate customer data and communications across the lifecycle while improving relevance, retention, and operational consistency.

## Example

A lifecycle team could operationalize Composable CDP in its customer-engagement stack so user behavior changes which message, channel, or experience is delivered next.
