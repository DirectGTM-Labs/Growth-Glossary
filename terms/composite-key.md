# Composite Key

## Definition

A composite key is a key whose uniqueness is defined by two or more columns or attributes together.

## 中文定义

数据库里没法用单一 ID 认出这行数据，必须把“活动ID + 奖品ID”绑在一起做唯一的身份证。
