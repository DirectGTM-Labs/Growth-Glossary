# Core Web Vitals

## Definition

Core Web Vitals are Google’s user-experience metrics for loading, responsiveness, and visual stability, currently centered on LCP, INP, and CLS.

## 中文定义

Google 衡量网页加载体验的关键技术指标。

## Why It Matters

Understanding Core Web Vitals helps a growth practitioner make clearer decisions, define measurement correctly, and avoid confusing a useful tactic or implementation detail with a universal growth law.
