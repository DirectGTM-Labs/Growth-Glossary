# Data Lake

## Definition

A data lake is a storage environment designed to hold large volumes of data in varied formats, often retaining raw or lightly processed data for later processing and analysis.

## 中文定义

数据湖是用于存储大规模、多种格式数据的环境，通常保留原始或轻度处理的数据，以便后续处理和分析。

## Why It Matters

A lake can preserve raw data and support flexible downstream processing, especially when data types and use cases evolve.

## Example

Raw application events, files, and exports are stored in object storage before being transformed for analytics.
