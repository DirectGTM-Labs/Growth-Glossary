# Docker

## Definition

Docker packages applications and their dependencies into portable containers that share the host operating system kernel.

## 中文定义

把你的代码连同它依赖的环境打包成一个绝对不走样的“集装箱”，丢到任何服务器都能正常运行。

## Why It Matters

Understanding Docker helps a growth practitioner make clearer decisions, define measurement correctly, and avoid confusing a useful tactic or implementation detail with a universal growth law.

A growth engineering team can use Docker as part of a production workflow where reliability, observability, security, and measurable outcomes are defined explicitly.
