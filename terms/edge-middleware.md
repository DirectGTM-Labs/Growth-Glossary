# Edge Middleware

## Definition

Edge middleware executes request-time logic at edge locations before or around application routing, enabling low-latency personalization, redirects, authentication, and experimentation.

## 中文定义

代码不跑在中心机房，而是跑在距离用户地理位置最近的 CDN 节点上（如 Cloudflare Workers），速度惊人。
