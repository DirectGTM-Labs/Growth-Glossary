# Electron

## Definition

Electron is a desktop application framework that combines Chromium and Node.js so web technologies can be used to build cross-platform applications.

## 中文定义

将整个完整的 Chrome 内核和 Node.js 塞进去，用网页技术开发跨平台重型桌面软件（如 VS Code）的技术。
