# Event Property

## Definition

A key-value attribute attached to an event that provides context about what happened, such as product ID, page URL, plan, or revenue.

## 中文定义

事件属性是附着在某个事件上的键值信息，用来补充描述该事件发生时的上下文，例如商品 ID、页面 URL 或金额。

## Why It Matters

It helps teams coordinate customer data and communications across the lifecycle while improving relevance, retention, and operational consistency.

## Example

A lifecycle team could operationalize Event Property in its customer-engagement stack so user behavior changes which message, channel, or experience is delivered next.
