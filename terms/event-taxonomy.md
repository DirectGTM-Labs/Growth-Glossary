# Event Taxonomy

## Definition

A governed naming and classification system for analytics events and properties so behavioral data remains consistent and interpretable.

## 中文定义

事件分类体系是对分析事件和属性进行统一命名、分组和语义治理的规范，使行为数据保持一致和可解释。

## Why It Matters

It helps teams coordinate customer data and communications across the lifecycle while improving relevance, retention, and operational consistency.

## Example

A lifecycle team could operationalize Event Taxonomy in its customer-engagement stack so user behavior changes which message, channel, or experience is delivered next.
