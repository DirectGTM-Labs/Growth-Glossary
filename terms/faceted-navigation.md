# Faceted Navigation

## Definition

A navigation system that creates filterable URL combinations from product or content attributes, which can generate large crawl spaces if not controlled.

## 中文定义

分面导航是根据属性筛选生成大量 URL 组合的导航系统，如果没有控制，可能形成非常大的抓取空间。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit Faceted Navigation during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
