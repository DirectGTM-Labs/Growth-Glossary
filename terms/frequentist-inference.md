# Frequentist Inference

## Definition

Frequentist inference treats model parameters as fixed but unknown quantities and evaluates procedures through the long-run behavior of repeated samples. P-values and confidence intervals are common frequentist tools.

## 中文定义

频率学派推断将模型参数视为固定但未知的量，并通过重复抽样下统计程序的长期性质进行推断；p 值和置信区间是常见工具。

## Why It Matters

It provides a well-established framework for hypothesis testing and interval estimation, including many conventional online-experimentation procedures.

## Example

A team pre-specifies an alpha level and computes a confidence interval for the treatment effect using a frequentist model.
