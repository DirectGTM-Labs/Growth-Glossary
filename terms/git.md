# Git

## Definition

Git is a distributed version-control system for tracking changes, branching, merging, and collaborating on source code and other text-based assets.

## 中文定义

极客的后悔药系统，可以无限次将代码撤回到过去任何一个无 bug 的状态节点。

## Why It Matters

Understanding Git helps a growth practitioner make clearer decisions, define measurement correctly, and avoid confusing a useful tactic or implementation detail with a universal growth law.

## Example

A growth engineering team can use Git as part of a production workflow where reliability, observability, security, and measurable outcomes are defined explicitly.
