# Headless Browser

## Definition

A headless browser is a browser runtime operated without a visible graphical interface, often used for automation, testing, rendering, and crawling.

## 中文定义

运行在无显示器的 Linux 服务器后台的完整浏览器，专用于偷偷执行 JS 爬虫作业。
