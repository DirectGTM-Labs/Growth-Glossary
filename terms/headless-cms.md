# Headless CMS

## Definition

A headless CMS separates content management from presentation and exposes content through APIs so multiple frontends can consume the same source.

## 中文定义

把前端长相和后台数据彻底分离的架构。后台传完图文，App、小程序、官网通过 API 各自调走自己需要的部分。
