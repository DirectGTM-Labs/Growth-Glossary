# Hreflang Tags

## Definition

Hreflang annotations indicate language and regional variants of equivalent pages so search engines can select an appropriate version for users.

## 中文定义

出海关键代码。明确告诉 Google，这个 URL 给美国英语看，那个 URL 虽然也是英语但是给英国人用英镑看。
