# HTTP Status Code

## Definition

A three-digit response code that communicates the result of an HTTP request, such as success, redirection, client error, or server error.

## 中文定义

HTTP 状态码是服务器用三位数字表达一次 HTTP 请求结果的标准代码，例如成功、重定向、客户端错误和服务器错误。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit HTTP Status Code during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
