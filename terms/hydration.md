# Hydration

## Definition

The process of attaching client-side JavaScript behavior and state to server-rendered or statically generated HTML.

## 中文定义

前端水合是把客户端 JavaScript 的状态和交互能力绑定到服务端渲染或静态生成 HTML 上的过程。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit Hydration during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
