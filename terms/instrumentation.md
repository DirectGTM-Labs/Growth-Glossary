# Instrumentation

## Definition

Instrumentation is the addition of code or configuration that emits data about software behavior, performance, events, or state so that the system can be measured and observed.

## 中文定义

插桩/埋点（Instrumentation）是在软件中加入代码或配置，使系统能够输出关于行为、性能、事件或状态的数据，从而支持测量与可观测性。

## Why It Matters

Without appropriate instrumentation, teams cannot reliably measure user behavior or system outcomes.

## Example

A signup flow emits structured events when a user views the form, submits it, encounters validation errors, and completes registration.
