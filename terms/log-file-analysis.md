# Log File Analysis

## Definition

The analysis of web-server request logs to understand crawler behavior, request frequency, response codes, URL discovery, and technical issues.

## 中文定义

服务器日志分析通过研究真实请求日志来理解搜索爬虫访问频率、URL、响应状态、抓取行为和技术异常。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit Log File Analysis during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
