# Multivariate Test (MVT)

## Definition

A multivariate test evaluates multiple factors or interface elements simultaneously, using combinations of factor levels to estimate main effects and, where designed and powered appropriately, interactions.

## 中文定义

多变量测试（MVT）同时评估多个因素或界面元素，通过不同因素水平的组合估计主效应，并在设计和统计功效允许时估计交互效应。

## Why It Matters

It can reveal interactions between changes that cannot be observed by testing each factor only in isolation, but it generally requires substantially more traffic and careful design.

## Example

A landing page experiment varies headline, hero image, and CTA copy across a factorial set of combinations.
