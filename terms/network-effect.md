# Network Effect

## Definition

A network effect occurs when additional users change the value of a product for other users; direct, indirect, and two-sided forms are commonly distinguished.

## 中文定义

网络效应壁垒。新进来一个人，让已经待在里面所有人的价值全都变高（你加了微信，你全家微信的价值都涨了）。

## Why It Matters

Understanding Network Effect helps a growth practitioner make clearer decisions, define measurement correctly, and avoid confusing a useful tactic or implementation detail with a universal growth law.

## Example

For example, a growth team could use Network Effect to diagnose, design, measure, or improve a defined stage of the customer or product lifecycle.
