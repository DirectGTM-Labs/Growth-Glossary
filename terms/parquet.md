# Parquet

## Definition

Apache Parquet is a columnar storage format designed for efficient analytical workloads through compression, column pruning, and typed schemas.

## 中文定义

大数据世界最爱的存储格式。按“列”压缩存放，体积只有原始日志的十分之一，且能按列跳过无关数据，让你的查询账单直降 90%。
