# Puppeteer

## Definition

Puppeteer is a Node.js library for controlling Chromium-based browsers programmatically, commonly for automation, testing, and web interaction.

## 中文定义

用 Node.js 代码控制一个隐形 Chrome 浏览器的技术，常用于爬取需要 JS 渲染的高防网站。
