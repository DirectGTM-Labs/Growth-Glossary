# Purposeful Code

## Definition

Purposeful Code is a working principle in growth engineering in which product changes are implemented with explicit measurement, observability, and experimentability requirements when those requirements are relevant to the business question.

## 中文定义

目的导向型代码是增长工程中的一种工作原则：当业务问题需要衡量和实验时，在实现产品变化的同时明确考虑测量、可观测性和实验能力。

## Why It Matters

It helps ensure that important product changes can be evaluated with evidence instead of becoming unmeasured feature releases.

## Example

An onboarding component emits a documented activation event and carries experiment-assignment context so the team can evaluate the change.
