# Query Fan-Out

## Definition

The expansion of a user query into multiple related retrieval or search subqueries so a system can gather broader evidence before synthesizing an answer.

## 中文定义

查询扇出是把一个原始查询扩展为多个相关子查询或检索任务，以获得更广的证据集合后再综合生成答案的机制。

## Why It Matters

It affects how AI and retrieval systems find, select, ground, rank, or cite information, which is increasingly important for AI-mediated discovery.

## Example

A GEO or AI-search team could evaluate Query Fan-Out across a fixed query set and compare retrieval, citation, or answer-quality changes after content or data improvements.
