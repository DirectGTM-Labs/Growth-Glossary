# Redirect

## Definition

A server- or client-side mechanism that sends a user agent from one URL to another.

## 中文定义

重定向是让客户端或爬虫从一个 URL 转向另一个 URL 的服务器端或客户端机制。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit Redirect during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
