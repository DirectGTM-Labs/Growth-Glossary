# Redis

## Definition

Redis is an in-memory data store commonly used for caching, counters, queues, rate limiting, sessions, and other low-latency workloads.

## 中文定义

把数据全塞在内存里（不存硬盘）的极速缓存库，多用来存短期高频读取的数据（比如防刷帖的计数器）。
