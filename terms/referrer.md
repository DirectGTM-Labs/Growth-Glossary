# Referrer

## Definition

A referrer is information indicating the prior URL or source context from which a web request originated, when that information is available.

## Why It Matters

Understanding Referrer helps a growth practitioner make clearer decisions, define measurement correctly, and avoid confusing a useful tactic or implementation detail with a universal growth law.
