# Robots Meta Tag

## Definition

An HTML meta tag that provides supported search crawlers with page-level indexing and serving directives such as noindex or nofollow.

## 中文定义

Robots 元标签是在 HTML 页面中向支持它的搜索爬虫提供页面级索引和结果呈现指令的 meta 标签，例如 noindex。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit Robots Meta Tag during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
