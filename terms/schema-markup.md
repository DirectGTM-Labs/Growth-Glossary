# Schema Markup

## Definition

Schema markup is structured data embedded in a page to describe entities and properties using vocabularies such as Schema.org.

## 中文定义

给网页元素打标签，告诉 Google “299 是价格，不是乱写的数字”，有极大概率让网页在搜索结果里展示星级评分。
