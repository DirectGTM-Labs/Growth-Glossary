# Search Intent

## Definition

The underlying goal or task a user is trying to accomplish with a search query.

## 中文定义

搜索意图是用户输入一个查询时真正想完成的目标或任务，例如获取信息、比较方案、导航到某站点或完成交易。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit Search Intent during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
