# Semi-structured Data

## Definition

Semi-structured data contains organizational metadata such as keys, tags, or nested fields without requiring a fixed relational table schema.

## 中文定义

没有死板的行列结构，但内部自己包含层级规则的数据，比如 JSON 文件。

## Why It Matters

Understanding Semi-structured Data helps a growth practitioner make clearer decisions, define measurement correctly, and avoid confusing a useful tactic or implementation detail with a universal growth law.

## Example

For example, a growth team could incorporate Semi-structured Data into an experiment, data pipeline, product system, or measurement workflow when the stated assumptions and implementation requirements are satisfied.
