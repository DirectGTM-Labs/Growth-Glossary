# Sitemap Index

## Definition

An XML file that lists multiple sitemap files, commonly used when a site has more URLs than should be placed in a single sitemap.

## 中文定义

站点地图索引是专门列出多个 sitemap 文件的 XML 文件，常用于 URL 数量较大的大型网站。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit Sitemap Index during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
