# Snowflake Schema

## Definition

A snowflake schema is an analytical schema in which dimensions are further normalized into related tables, reducing redundancy at the cost of more joins.

## 中文定义

星型模型的进阶版，维度表会被进一步拆分以减少数据冗余（类似雪花分叉）。
