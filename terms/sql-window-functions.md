# SQL Window Functions

## Definition

SQL window functions calculate values across related rows without collapsing them into a single grouped row, enabling rankings, running totals, and lag/lead analysis.

## 中文定义

SQL 里的高级大招，可以在不破坏大表结构的前提下，轻松算出一群用户的“第一次”或“最后一次”动作。
