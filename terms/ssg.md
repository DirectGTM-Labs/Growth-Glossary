# SSG

## Definition

Static site generation (SSG) produces HTML ahead of request time, typically during a build, so pages can be served efficiently as static assets.

## 中文定义

Next.js 在代码打包阶段，提前把网页固化成 HTML。上线后访问速度接近 0 毫秒，且 SEO 抓取率高达 100%。
