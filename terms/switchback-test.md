# Switchback Test

## Definition

A switchback test alternates treatment and control conditions across predefined time periods or other aggregate units when user-level randomization would be invalid or interference between units is substantial.

## 中文定义

切换测试是在用户级随机分流不适用或不同用户之间存在明显干扰时，按照预先定义的时间段或其他聚合单位交替运行处理组和对照组条件。

## Why It Matters

It is useful for systems where treatment changes the shared environment experienced by other participants.

## Example

A marketplace alternates two dispatch algorithms by time block while controlling for time-of-day effects.
