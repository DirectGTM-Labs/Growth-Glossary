# Tauri

## Definition

Tauri is a framework for building desktop applications with web frontends and lightweight native backends rather than bundling a full browser engine.

## 中文定义

抛弃臃肿的 Chromium，利用底层操作系统的原生能力去把 Web 网页打包成极小极快桌面 App 的现代框架。
