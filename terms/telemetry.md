# Telemetry

## Definition

Telemetry is data emitted by a system for remote measurement and observation, including signals such as logs, metrics, and traces.

## 中文定义

遥测（Telemetry）是系统为远程测量和观察而产生并传出的数据，常见信号包括日志、指标和链路追踪。

## Why It Matters

Telemetry provides the raw evidence used by observability, monitoring, debugging, and some growth analytics systems.

## Example

A service emits request latency metrics, structured error logs, and distributed traces for production requests.
