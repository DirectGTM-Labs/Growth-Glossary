# Type II Error

## Definition

Failing to reject a false null hypothesis when a real effect exists.

## 中文定义

第二类错误是在真实效应存在、原假设为假时，却没有拒绝原假设的情况。

## Why It Matters

It is part of designing, operating, or interpreting controlled experiments with enough rigor to distinguish causal signal from noise.

## Example

An experimentation team could document Type II Error in the experiment design or analysis plan before launch so the resulting decision is statistically and operationally defensible.
