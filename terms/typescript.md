# TypeScript

## Definition

TypeScript is a statically typed superset of JavaScript that adds compile-time type checking and related language features.

## 中文定义

微软开发的带严格类型检查的 JavaScript 超集。2026年防前端手抖引发低级崩溃的绝对唯一标准。
