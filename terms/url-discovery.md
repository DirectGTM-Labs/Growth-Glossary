# URL Discovery

## Definition

The process by which a search engine learns that a URL exists, commonly through links, sitemaps, feeds, redirects, or prior crawl history.

## 中文定义

URL 发现是搜索引擎通过链接、站点地图、Feed、重定向或历史记录得知某个 URL 存在的过程。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit URL Discovery during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
