# URL Inspection

## Definition

The examination of how a specific URL is discovered, crawled, rendered, indexed, and represented by a search engine using diagnostic tooling such as Google Search Console.

## 中文定义

URL 检查是借助 Search Console 等诊断工具查看单个 URL 的发现、抓取、渲染、索引和规范化状态。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit URL Inspection during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
