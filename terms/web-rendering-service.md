# Web Rendering Service (WRS)

## Definition

Google's rendering system that executes supported JavaScript and processes pages so content produced after initial HTML can be considered during indexing.

## 中文定义

Web 渲染服务是 Google 用于执行受支持 JavaScript 并处理网页渲染结果的系统，使动态生成内容能够参与后续索引处理。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit Web Rendering Service (WRS) during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
