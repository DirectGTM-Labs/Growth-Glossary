# Webhook

## Definition

A webhook is an HTTP callback in which one system sends an event notification to a URL exposed by another system.

## 中文定义

一种让一个系统在发生事件时，主动“打电话（发 HTTP 请求）”通知另一个系统的极简 API 通信方式。
