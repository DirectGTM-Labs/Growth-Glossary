# X-Robots-Tag

## Definition

An HTTP response header used to send robots indexing or serving directives, including for non-HTML resources.

## 中文定义

X-Robots-Tag 是通过 HTTP 响应头发送索引或结果呈现指令的方式，尤其适合 PDF 等非 HTML 资源。

## Why It Matters

It affects how search systems discover, render, understand, index, or present content and therefore influences organic discoverability and technical search health.

## Example

An SEO team could audit X-Robots-Tag during a technical review and verify the result with crawler diagnostics, server logs, or Search Console where applicable.
